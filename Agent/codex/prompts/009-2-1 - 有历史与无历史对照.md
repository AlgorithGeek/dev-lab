# 009-2-1：有历史与无历史对照

2026-10-20，用户已理解对照方案，要求：“懂了，你先把有历史和无历史的对照实验代码写出来吧，我们一步一步来。”

按 009-2 的 Checkpoint 2 实现第一阶段：

- 保留 FirstModelCall，新增同包 MessageHistoryDemo。
- 沿用 Java 21、JDK HttpClient、FastJSON2；不增加依赖。
- 从运行环境读取 DASHSCOPE_API_KEY / DASHSCOPE_BASE_URL，校验后追加 /chat/completions。
- 使用 qwen3.8-max 和 reasoning_effort=none。
- seed 发送：本次对话的实验代号是青柠47。请只回复“收到”。保存实际 assistant.content。
- A 只发送第二轮问题；B 按顺序发送第一轮 User、seed 的实际 Assistant、相同的第二轮问题。

- 非 2xx 不解析成功字段，非法 JSON / 缺失字段明确报错；失败停止，无自动重试。
- 编译并用假密钥、本地 HTTPS 模拟核对消息、转义和失败路径；真实 API 由用户在 IDEA 中运行。
- 保存协作记录，停在第一阶段，不实现自动维护历史，不更新节点完成状态，不提交或推送。
