## 三次调用与读代码顺序

先看 main 中 firstQuestion / secondQuestion 和三个 JSONArray，再看 message，最后看 callModel。

| 调用 | 发送的 messages | 作用 |
|---|---|---|
| seed | User1：告知实验代号青柠47 | 从响应中取得 firstAnswer |
| A（无历史） | User2：追问代号 | 请求不含第一轮信息 |
| B（有历史） | User1、Assistant1、User2 | Assistant1 使用 firstAnswer，User2 与 A 相同 |

三组数组独立；A 的回答不会进入 B。Assistant1 不硬编码为“收到”，只取 seed 响应的 content，不保存整份 HTTP 响应或 usage。
message 构造 JSONObject；callModel 用 JSON.toJSONString 序列化整个请求，处理引号、反斜杠和换行。

callModel 校验 HTTP 状态、JSON、model、choices、content、finish_reason 与 usage。
非 2xx 输出状态及错误响应后停止，不读取成功字段；任意一步失败即以退出码 1 结束，不继续发下一次请求、不自动重试。
成功时打印标签、messages、HTTP Status、Model、Content、Finish Reason、三项 Tokens。
不主动打印 Key、Authorization 或完整私密 URL；未读取 IDEA 配置。
