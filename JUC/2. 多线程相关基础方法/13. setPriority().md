## `setPriority()`

`setPriority()` 用来设置线程优先级。

线程优先级可以理解成：告诉线程调度器，这个线程“可能更重要一点”。

但它不是命令，只是一个倾向。



### Java 线程优先级范围

Java 线程优先级从 1 到 10。

常用常量：

```java
Thread.MIN_PRIORITY  // 1
Thread.NORM_PRIORITY // 5
Thread.MAX_PRIORITY  // 10
```

默认优先级通常是：`5`



### 基本用法

```java
Thread t1 = new Thread(() -> {
    System.out.println("低优先级线程");
});

Thread t2 = new Thread(() -> {
    System.out.println("高优先级线程");
});

t1.setPriority(Thread.MIN_PRIORITY);
t2.setPriority(Thread.MAX_PRIORITY);

t1.start();
t2.start();
```



### 优先级高，不代表一定先执行

这是最重要的点。

线程优先级最终还是要看 JVM 和操作系统调度。

高优先级线程更可能被多分配一点执行机会，但不是说：

```text
优先级 10 一定先执行
优先级 1 一定后执行
```

这种理解是错的。



### 不建议用优先级控制业务顺序

如果你希望线程 A 一定在线程 B 前面执行，不应该靠 `setPriority()`。

更应该用这些方式：

- `join()`
- 锁
- `wait()` / `notify()`
- JUC 里的工具类，比如 `CountDownLatch`

`setPriority()` 更像是调度建议，不适合做业务流程控制。



### 优先级不合法会怎样？

如果设置小于 1 或大于 10 的优先级，会抛：`IllegalArgumentException`

```java
t.setPriority(11);
```

这就是不合法的。
