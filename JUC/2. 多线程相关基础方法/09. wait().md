## `wait()`

`wait()` 的作用是：让当前线程进入等待状态，并且释放当前对象的锁。

注意：`wait()` 不是 `Thread` 类的方法，而是 `Object` 类的方法。

也就是说，所有对象都可以调用 `wait()`。



### `wait()` 必须写在 `synchronized` 里面

比如：

```java
synchronized (lock) {
    lock.wait();
}
```

为什么？

因为线程调用 `lock.wait()` 的前提是：它现在已经拿到了 `lock` 这把锁。

如果没有拿到锁就调用 `wait()`，会报：`IllegalMonitorStateException`



### `wait()` 会释放锁

这是它和 `sleep()` 很大的区别。

```java
synchronized (lock) {
    lock.wait();
}
```

当线程执行到 `lock.wait()` 时：

1. 当前线程进入等待状态
2. 当前线程释放 `lock` 这把锁
3. 其他线程就有机会进入 `synchronized (lock)`

所以：

- `sleep()`：睡觉，但不放锁
- `wait()`：等待，并且放锁



### 被唤醒以后会马上执行吗？

不会。

线程从 `wait()` 被唤醒后，不是马上继续往下执行。

它还要先重新抢到 `lock` 这把锁，抢到了以后，才能从 `wait()` 后面继续执行。



### `wait()` 怎么醒？

常见几种情况：

- 其他线程调用同一把锁对象的 `notify()`
- 其他线程调用同一把锁对象的 `notifyAll()`
- 其他线程调用当前线程的 `interrupt()`
- 使用 `wait(long timeout)`，时间到了自动醒



### 示例

```java
public class WaitDemo {
    private static final Object lock = new Object();

    public static void main(String[] args) throws InterruptedException {
        Thread t = new Thread(() -> {
            synchronized (lock) {
                try {
                    System.out.println("子线程开始等待");
                    lock.wait();
                    System.out.println("子线程被唤醒了");
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        });

        t.start();

        Thread.sleep(1000);

        synchronized (lock) {
            lock.notify();
        }
    }
}
```



### 实际写法里为什么常用 `while`？

不建议这样写：

```java
synchronized (lock) {
    if (!ready) {
        lock.wait();
    }
}
```

更推荐这样写：

```java
synchronized (lock) {
    while (!ready) {
        lock.wait();
    }
}
```

原因是：线程醒来不代表条件一定满足。

可能是被错误唤醒，也可能是多个线程一起醒来后，条件已经被别的线程改掉了。

所以醒来以后要重新检查条件。
