## start() / run()

### `start()`

`start()`：启动一个新的线程，并让这个新线程去执行 `run()` 里面的代码

> main 线程调用 t.start()
>         ↓
> JVM 创建一个新的操作系统线程
>         ↓
> 新线程启动
>         ↓
> 新线程自动调用 t.run()

所以我们平时不是自己手动调用 `run()`，而是调用 `start()`



### `run()`

`run()`：是线程真正要执行的任务代码

如：

```java
Thread t = new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("这里就是 run 方法里的逻辑");
    }
});
```

>直接调用 `run()` 会怎么样？
>
>- 直接调用 `run()` 就和直接调用一个普通方法没什么区别，是由执行这条调用方法的线程去做的



### **为什么调用 `start()` 后会自动执行 `run()`？**

因为 `Thread` 类内部就是这样设计的，可以简单理解成：

```java
start() {
    创建新线程;
    新线程去执行 run();
}
```


### `start()` 能调用多次吗？

不能。

例如：

```java
Thread t = new Thread(() -> {
    System.out.println("hello");
});

t.start();
t.start();
```

会报错：`java.lang.IllegalThreadStateException`



原因是：一个 `Thread` 对象只能启动一次

线程生命周期大概是：NEW -> RUNNABLE -> TERMINATED
