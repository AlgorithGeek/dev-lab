## `setDaemon()`

`setDaemon(true)` 的作用是：把线程设置成守护线程。

守护线程可以理解成：给其他正常线程提供辅助服务的后台线程。



### 普通线程和守护线程

Java 里线程大概可以分成两类：

- 用户线程：普通线程，比如 `main` 线程、你自己创建的大多数线程
- 守护线程：后台辅助线程，比如垃圾回收相关线程

JVM 什么时候退出？

当所有用户线程都结束后，JVM 就会退出。

就算还有守护线程在运行，JVM 也不会为了守护线程继续活着。



### 示例

```java
public class DaemonDemo {
    public static void main(String[] args) {
        Thread t = new Thread(() -> {
            while (true) {
                System.out.println("守护线程正在运行");
            }
        });

        t.setDaemon(true);
        t.start();

        System.out.println("main 线程结束");
    }
}
```

这里 `main` 线程结束后，JVM 很快就会退出。

守护线程不会一直把程序撑住。



### `setDaemon()` 必须在 `start()` 前调用

正确：

```java
Thread t = new Thread(() -> {});
t.setDaemon(true);
t.start();
```

错误：

```java
Thread t = new Thread(() -> {});
t.start();
t.setDaemon(true);
```

线程启动以后再设置守护线程，会报：`IllegalThreadStateException`



### 守护线程适合做什么？

它适合做一些后台辅助工作。

但不要把必须完整执行完的业务逻辑放到守护线程里。

因为 JVM 退出时，守护线程可能还没来得及收尾，就直接结束了。

比如下面这些就不适合完全依赖守护线程：

- 写重要文件
- 保存订单
- 提交关键日志
- 释放必须手动释放的外部资源
