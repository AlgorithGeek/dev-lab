## `currentThread()`/`xxxName()`

### `Thread.currentThread()` 是什么？

它是 `Thread` 类的静态方法。作用是：返回当前正在执行这行代码的线程对象。

比如：

```java
public class ThreadDemo {
    public static void main(String[] args) {
        Thread thread = Thread.currentThread();

        System.out.println(thread);
    }
}
```

输出类似：`Thread[main,5,main]`

> 这里说明当前执行代码的是 `main` 线程



### `getName()`：获取线程名

每个线程都有名字。就算你没有手动给设定，他也有。

`Thread.currentThread().getName()`就是获取当前执行这句代码的线程的名字

例如：

```java
Thread t1 = new Thread(() -> {
    System.out.println(Thread.currentThread().getName());
});

Thread t2 = new Thread(() -> {
    System.out.println(Thread.currentThread().getName());
});

t1.start();
t2.start();
```

输出可能是：

`Thread-0`

`Thread-1`

默认情况下，Java 会给线程起这种名字：

`Thread-0`

`Thread-1`

`Thread-2`

`...`



### `setName()`：设置线程名

默认的线程名(`Thread-0`、`Thread-1` ... )不太好看，也不方便排查问题

所以我们可以自己设置线程名字

```java
Thread t = new Thread(() -> {
    System.out.println(Thread.currentThread().getName());
});

t.setName("用于下载的线程");

t.start();
```

输出：`用于下载的线程`



### 更推荐的写法：创建线程时直接起名

除了 `setName()`，还可以在创建线程的时候直接传名字。

```java
Thread t = new Thread(
    () -> {System.out.println(Thread.currentThread().getName());}, 
    "用于下载的线程"
);

t.start();
```

输出：`用于下载的线程`

这种写法更常见，也更清晰



### 能不能修改 main 线程的名字？

可以。不过实际开发里一般不这么干
