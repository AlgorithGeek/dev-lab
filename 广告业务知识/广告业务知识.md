# 广告业务知识

## 账号之间的关系

1. 员工可以在广告平台上有自己的 **用户账号**

   这个账号是人登录用的，比如 Meta 用户、Google 用户、TikTok Business 用户

2. 公司里的负责人或平台对接人，用某个公司可控的用户账号创建 / 开通 BM

   这个用户账号最好绑定公司邮箱、公司手机号、企业认证信息，不建议用私人不可控账号

3. BM 不是普通登录账号，而是 **公司级管理空间 / 资产容器**

   它有 ID，看起来像“账号”，但本质更像组织空间

4. 创建 BM 的那个用户，通常会成为这个 BM 的初始管理员

   他可以管理 BM 里的广告账号、用户、资产、权限关系

5. 后续新员工创建自己的用户账号

   管理员把新员工邀请进 BM，并给他分配某些广告账号的权限

6. 分配好后，新员工用自己的用户账号登录官方广告平台

   他就能看到并操作自己被授权的广告账号，以及这些广告账号下面的 Campaign / AdSet / Ad



## 出价相关的一些术语

### 投放目标 (**Objective**)

> 它是创建 Campaign 时很上层的选择
>
> - 回答：*我这次投广告的业务大方向是什么？*

它通常是平台给运营选择的选项。不同平台名字不一样，但大概都类似

常见投放目标：

| 英文          | 中文     | 大白话                           |
| :------------ | :------- | :------------------------------- |
| APP_PROMOTION | 应用推广 | 推 App，让用户安装或打开 App     |
| APP_INSTALLS  | 应用安装 | 重点拿 App 安装量                |
| TRAFFIC       | 流量     | 把用户带到网站、落地页、App 页面 |
| CONVERSIONS   | 转化     | 让用户完成注册、购买、订阅等事件 |
| SALES         | 销售     | 推商品、订单、购买               |
| AWARENESS     | 品牌认知 | 让更多人看到品牌或产品           |
| LEADS         | 线索收集 | 收集表单、电话、潜在客户信息     |
| ENGAGEMENT    | 互动     | 点赞、评论、分享、关注           |
| VIDEO_VIEWS   | 视频观看 | 让更多人看视频                   |



比如运营创建广告时先选：`我要推广 App `

那投放目标可能就是：`APP_PROMOTION / APP_INSTALLS `

如果运营说：`我要卖商品 `

投放目标可能就是：`SALES / CONVERSIONS`



投放目标会影响后续能选什么，比如：

投放目标 = APP_PROMOTION  -> 后面可能能选安装、应用内事件、ROAS 等优化目标 

投放目标 = TRAFFIC  -> 后面可能能选点击、落地页浏览 

投放目标 = LEADS  -> 后面可能能选表单提交、线索 



**投放目标是第一层大方向，平台会根据它限制后面的优化目标、计费方式、出价策略**





### 优化目标 (Optimization Goal)

> *我希望平台的算法帮我找什么样的用户？*
>
> - 有些优化目标本身已经很具体，比如点击、展示、安装。
>
> - 但有些优化目标只是一个大类，比如转化、应用内事件、价值优化。这类目标通常还需要搭配“事件”一起使用，才能表达完整意思。
>
>   公式：转化类优化目标 + 事件 = 完整的优化目标表达
>
>   比如：
>
>   - 优化目标：转化
>   - 事件：Purchase
>
>   大白话：平台帮我找更可能购买的人。
>
>   再比如：
>
>   - 优化目标：应用内事件
>   - 事件：key_action_10TP
>
>   大白话：平台帮我找更可能完成 key_action_10TP 这个 App 内行为的人

运营人员 **首先需要选 投放目标，再在这个投放目标允许的范围里选择 优化目标**



#### 常见优化目标

| 优化目标   | 英文常见值                                    | 大白话                           |
| :--------- | :-------------------------------------------- | :------------------------------- |
| 点击       | CLICK / LINK_CLICKS                           | 找更容易点击广告的人             |
| 落地页浏览 | LANDING_PAGE_VIEW / TRAFFIC_LANDING_PAGE_VIEW | 找点进去后更可能真正打开页面的人 |
| 安装       | INSTALL / APP_INSTALLS                        | 找更可能安装 App 的人            |
| 转化       | CONVERSION / CONVERSIONS / CONVERT            | 找更可能完成指定事件的人         |
| 购买       | PURCHASE                                      | 找更可能购买的人                 |
| 应用内事件 | IN_APP_EVENT / EVENT_OPTIMIZATION             | 找更可能完成 App 内事件的人      |
| 价值       | VALUE / PURCHASE_VALUE                        | 找更可能带来高收入的人           |
| ROAS       | ROAS / VO_MIN_ROAS                            | 找更可能带来回报的人             |
| 留存       | RETENTION                                     | 找更可能留下来的用户             |
| 展示/覆盖  | REACH / IMPRESSIONS                           | 找更容易被触达的人群             |



#### 优化目标的影响

优化目标会影响很多东西，比如：

- 可选计费方式
- 可选出价策略
- 需要传的转化事件
- 平台算法学习方向
- 能不能修改某些出价字段
- 等



#### 为什么优化目标会影响出价

因为不同优化目标的“价格含义”不同。

- 如果优化目标是点击：出价值可能表示每次点击愿意付多少钱 

- 如果优化目标是转化：出价值可能表示每次转化愿意付多少钱 

- 如果优化目标是 ROAS：出价值可能表示目标回报率，比如 200% 



所以同样一个 bid=550：

- 点击类：可能表示点击成本 
- 转化类：可能表示转化成本 
- ROAS 类：就不是钱了，可能是 550% 或另一个比例 

这就是出价开发必须先看优化目标的原因。



### 事件 / 转化事件 / 自定义事件

> **优化目标决定平台大概要找哪类结果；事件在转化类/应用内事件类目标下，进一步指定“到底是哪一个具体行为”**

优化目标会影响事件能不能选，事件是某些优化目标下面需要进一步指定的具体行为

#### 基本概念

在广告业务里，事件指的是用户在 App 或网站里完成的某个行为

比如：

- 用户安装 App
- 用户打开 App
- 用户注册
- 用户购买
- 用户订阅
- 用户浏览商品
- 用户完成公司定义的关键动作

这些行为如果被 App SDK、Pixel 或服务端接口上报给广告平台，就可以成为广告平台里的事件





#### 事件和优化目标的关系

不是所有优化目标都需要选择事件。

如果优化目标是点击、展示、覆盖这类目标，平台只需要知道我要找容易点击或容易看到广告的人，通常不需要选择转化事件。

如果优化目标是转化、应用内事件、购买、线索这类目标，平台需要知道具体要优化哪个用户行为，这时就需要选择事件。

所以：

- 优化目标 = 平台帮我找什么人
- 事件 = 如果目标是转化类，那具体要找完成哪个行为的人

比如：

- 优化目标：点击  
  
  事件：不需要
  
- 优化目标：安装  
  
  事件：可能不需要单独选择，安装本身就是目标
  
- 优化目标：应用内事件  
  
  事件：需要选择 App 事件，比如 PURCHASE 或 key_action_10TP
  
- 优化目标：网站转化  
  
  事件：需要选择 Pixel 事件，比如 PURCHASE 或 Lead



#### App 事件和 Pixel 事件

App 事件：发生在 App 里的用户行为

比如：

- 打开 App
- App 内注册
- App 内购买
- App 内完成某个关键动作



Pixel 事件：发生在网站里的用户行为

比如：

- 浏览网页
- 点击按钮
- 提交表单
- 网站购买



#### 标准事件和自定义事件

##### **标准事件**

标准事件就是平台提前定义好的通用用户行为。

也就是说，Meta 官方已经规定了这些事件名和大概用途。你上报的时候最好按它的名字来，创建广告时平台也知道这些事件属于哪一类

比如 Meta 里的：

- PURCHASE

  >中文可以理解成：购买。
  >
  >用户完成付费、下单、订阅成功时，可以上报这个事件。

- COMPLETE_REGISTRATION

  > 中文可以理解成：完成注册。
  >
  > 用户注册账号成功、填写完注册流程时，可以上报这个事件

- VIEW_CONTENT

  > 中文可以理解成：查看内容。
  >
  > 用户查看商品详情页、内容页、落地页里的关键内容时，可以上报这个事件

- ADD_TO_CART

  > 中文可以理解成：加入购物车。
  >
  > 电商场景里，用户把商品加入购物车时可以上报这个事件







自定义事件是公司自己定义的业务行为。

比如：

- key_action_10TP

  > 这个名字 Meta 不一定知道业务含义。但公司内部可能知道：这是某个关键行为，比如完成 10 次关键动作、达到某个活跃门槛、触发某个重要页面

- paywall_view

  > 可以理解成：用户看到了付费墙/订阅页。
  >
  > 这个事件对订阅类产品很重要，因为用户看到付费页，说明已经比较接近付费了

- trial_start

  > 可以理解成：开始试用。
  >
  > 比如用户领取 7 天免费试用，这个行为比普通注册更有价值

再举几个更贴近业务的例子：

- chapter_read_3

  > 用户读完 3 个章节

- first_prayer_done

  > 用户完成第一次祷告/第一次核心动作

- level_5_reached

  > 游戏用户达到 5 级

Meta 不一定理解这个名字的业务含义，但只要 App / 网站真实上报过这个事件，Meta 就知道哪些用户发生过它，并可以用这些数据做归因、统计和优化学习



#### 创建广告时为什么要选事件

创建广告时选择事件，本质是在告诉平台：**这个广告组投出去以后，平台应该围绕哪个用户行为去优化**

比如：

- 优化目标：转化
- 事件：key_action_10TP

大白话就是：

你这组广告不要只找容易点击的人，也不要只找容易安装的人。你帮我找更可能完成 key_action_10TP 这个行为的人



#### 事件和报表的关系

用户通过广告进入 App / 网站后，如果完成了这个事件，并且平台能归因到广告，就会在报表里形成对应的转化数据。

比如：

- 花费 100 美元
- 安装 200 个
- key_action_10TP 40 个

运营就可以判断：

这个广告组不只是带来了安装，还带来了多少关键行为。





### 计费方式 (Billing/Billing Event)

> 平台根据什么计费触发点扣我的钱

#### 常见计费方式

| 计费方式       | 英文              | 大白话                   |
| :------------- | :---------------- | :----------------------- |
| 按展示计费     | CPM / IMPRESSIONS | 按曝光收费               |
| 按点击计费     | CPC / CLICKS      | 按点击收费               |
| 按安装计费     | CPI / INSTALLS    | 按安装收费，某些平台支持 |
| 按转化计费     | CPA / CONVERSIONS | 按转化收费，某些平台支持 |
| 按视频播放计费 | CPV / VIDEO_VIEWS | 按播放收费               |



#### 计费方式和优化目标可以不一样

这是最容易绕的地方

比如一个 App 安装广告：

- 投放目标：App Promotion 

- 优化目标：Install 
- 计费方式：CPM 



意思是：

> 平台算法帮你找更可能安装 App 的人，但平台实际按展示次数向你收费

也就是说，平台可能不是等用户真的安装了才扣钱，而是广告展示出去就开始计费



最后你再通过报表算：CPI = 花费 / 安装数 

所以同一个广告可以是：

- 优化目标：INSTALL 
- 计费方式：CPM 
- 业务指标：CPI 

这三个不冲突



**为什么平台会这样设计**

- 因为现代广告平台大多是竞价广告。平台卖的是流量曝光机会，但算法会根据你选的优化目标去挑人

问题：

- 既然平台要按照展示扣费，但是优化目标是找更可能安装的人，那我们不就亏了？ 为啥运营人员不选择`CPI`，也就是按照安装扣费呢？

  >*如果我想要安装，那平台按安装收费不是最安全吗？为什么还要按展示收费，万一展示很多但没人安装，不就亏了吗？*

  - 答案：

    **理论上 CPI 按安装付费更稳，但现实里平台不一定给你这个选项，或者给了也会有代价**

    如果是 CPI 计费：用户安装了，我才付钱 用户没安装，我不付钱

    站在广告主角度，听起来非常舒服。

    但站在平台角度，风险就变成平台承担：平台给你展示了很多次 但用户没安装 平台就收不到钱

    所以平台不会随便让所有广告都按安装收费

    因为展示是平台最可控的资源。

    平台卖的是广告流量，本质上是：我把广告展示机会卖给你

    ......



### 出价策略 (Bid Strategy)

>*平台参与广告竞价时，应该怎么帮我花钱、控成本、控回报？*

是运营人员选择的



#### 常见出价策略

##### Lowest Cost / Lowest Cost Without Cap

中文叫：最低成本/不设成本上限的最低成本

大白话：*平台尽量用最低成本帮你拿最多结果，但你不给它明确的成本上限。*

特点：

- 自动化程度高
- 更容易跑量
- 不需要或较少需要填具体 bid
- 成本可能波动
- 你控制力较弱

适合：

- 想快速跑量
- 对成本波动容忍度较高
- 还在探索阶段

但对出价开发来说：

- 这种策略通常不能手动改普通 bid_amount 

  比如 Facebook 里 LOWEST_COST_WITHOUT_CAP 就不能用普通 bid_amount 去改



##### Cost Cap

中文叫：成本上限/目标成本控制

大白话：平台尽量拿结果，同时努力让平均成本不要超过手动设置的目标

例子：

- 目标 CPI = 5.5 美元

  平台会尽量让平均安装成本接近这个目标

特点：

- 兼顾跑量和控成本
- 需要填目标成本
- 成本可能短期波动
- 长期平均成本更重要

适合：希望稳定控制 CPI / CPA 但也想有一定放量能力



##### Bid Cap

中文叫：出价上限/单次竞价上限

大白话：每一次竞价，平台最多只能出到这个价格

例子：Bid Cap = 3 美元 

意思是：平台参与单次竞价时，不许超过 3 美元



特点：

- 控制最严格
- 可能导致跑不出量
- 平台灵活性低
- 更适合很懂流量价格的人



和 Cost Cap 的区别：

- Cost Cap 控制平均结果成本 
- Bid Cap 控制每次竞价最高出价



##### Target CPA

中文叫：目标转化成本

大白话：*平台围绕每次转化成本目标去投*

例子：

Target CPA = 10 美元 

意思是：希望每个购买/注册/转化的平均成本接近 10 美元

特点：

- 目标明确
- 依赖转化数据
- 平台会围绕 CPA 优化
- 有些平台把它作为 Campaign 层策略

Google 出价里很典型：

```
TARGET_CPA  
	-> target_cpa_micros
```



##### Target ROAS

中文叫：目标广告回报率

大白话：*平台帮你找更高价值用户，目标是达到某个收入/花费比例。*

例子：Target ROAS = 200% 

意思是：希望花 1 美元，带来 2 美元收入

特点：

- 不是成本目标，是回报目标
- 依赖收入回传
- 对数据质量要求高
- 通常更适合付费/订阅/电商类业务

Google 出价里：

```
TARGET_ROAS  
	-> target_roas = 2.0 
```

TikTok 里可能对应：

```
roas_bid
```



##### Min ROAS / Lowest Cost With Min ROAS

中文叫：最低 ROAS/带最低 ROAS 约束的最低成本

大白话：*平台尽量拿量，但要求回报率不能低于某个水平*

例子：Min ROAS = 150% 

意思是：可以帮我跑量，但回报率至少要接近 1.5 倍。

这类策略经常不能用普通金额出价字段去改。

比如 Facebook：

```
LOWEST_COST_WITH_MIN_ROAS  
	-> 不支持普通 bid_amount  
	-> 应该看 bid_constraints / ROAS 相关字段
```



##### Maximize Conversions

中文叫：最大化转化

大白话：*在预算范围内尽可能多拿转化*

特点：

- 更自动化
- 不一定让你设置具体 CPA
- 适合平台自动优化
- 成本控制可能弱一些

Google 中常见：MAXIMIZE_CONVERSIONS 

我们当前项目的 Google 出价实现里，暂时不支持它作为普通改价目标



##### Maximize Conversion Value

中文叫：最大化转化价值

大白话：*不只是拿转化数量，而是尽量拿更高价值转化*

比如两个用户都会购买：

- 用户 A 可能买 1 美元 
- 用户 B 可能买 100 美元 

平台会更偏向用户 B。

适合：电商 订阅 游戏付费 有收入回传的数据场景



#### 表格整理

| 出价策略       | 英文                                  | 大白话                                 |
| :------------- | :------------------------------------ | :------------------------------------- |
| 最低成本       | LOWEST_COST / LOWEST_COST_WITHOUT_CAP | 尽量拿最多结果，不设明确成本上限       |
| 成本上限       | COST_CAP                              | 尽量让平均成本不超过目标               |
| 出价上限       | BID_CAP                               | 每次竞价出价不超过某个值               |
| 目标成本       | TARGET_COST                           | 尽量稳定在某个目标成本附近             |
| 目标 CPA       | TARGET_CPA                            | 目标每次转化成本                       |
| 目标 ROAS      | TARGET_ROAS                           | 目标回报率                             |
| 最低 ROAS      | MIN_ROAS / LOWEST_COST_WITH_MIN_ROAS  | 回报率不能低于某个目标                 |
| 最大化转化     | MAXIMIZE_CONVERSIONS                  | 尽量拿更多转化，可能不让你手动设置 CPA |
| 最大化转化价值 | MAXIMIZE_CONVERSION_VALUE             | 尽量拿更多价值                         |

出价策略不是结果指标，而是平台竞价逻辑



#### 一次能选几个策略

通常一个广告对象只有一个 **主出价策略**

比如：

- Cost Cap 
- Target CPA 
- Target ROAS 
- Lowest Cost 

一般不会让你自由叠加多个主策略。

但平台可能有一些附加约束，导致名字看起来像组合：LOWEST_COST_WITH_MIN_ROAS 

这看起来像：Lowest Cost + Min ROAS ，但在平台里通常是一个具体策略枚举。

所以先记：主出价策略通常一个 附加约束可能有 具体以平台枚举和 API 文档为准



#### 出价策略和出价值的关系

有些策略需要出价值，有些不需要。

| 出价策略                  | 是否通常需要出价值 | 出价值含义          |
| :------------------------ | :----------------- | :------------------ |
| Lowest Cost               | 通常不需要         | 系统自动            |
| Cost Cap                  | 需要               | 目标成本            |
| Bid Cap                   | 需要               | 单次竞价上限        |
| Target CPA                | 需要               | 目标转化成本        |
| Target ROAS               | 需要               | 目标 ROAS           |
| Min ROAS                  | 需要               | 最低 ROAS 要求      |
| Maximize Conversions      | 通常不需要或可选   | 系统自动            |
| Maximize Conversion Value | 通常不需要或可选   | 系统自动或附加 ROAS |

所以出价开发时不能只看：bid = 550 

还要看：

- 当前出价策略是什么？ 
- 这个策略需不需要 bid？ 
- 这个 bid 是金额还是 ROAS？ 
- 应该写到哪个平台字段？







### 出价值 (Bid Value)

>*我要给平台的那个数字是多少？*

这个数字可能是金额，也可能是 ROAS 比例



#### 出价值类型

常见大概分三类：

##### **金额型出价值**

比如：

- bid_amount = 200 

  target_cpa = 5000000 

  micros cpa_bid = 10 USD 

它表达的是钱。

可能代表：

- 目标点击成本 CPC 
- 目标安装成本 CPI 
- 目标转化成本 CPA 
- 最高竞价 BID CAP 
- 目标成本 COST CAP 



##### **比例型出价值**

比如：

- target_roas = 2.5 

  roas_bid = 300 

它表达的是回报率

比如：target_roas = 2.5 

大白话就是：我希望广告收入 / 广告花费 = 2.5，也就是 250%



##### **无出价值**

有些策略根本不需要你填出价值。

比如：

- LOWEST_COST 
- MAXIMIZE_CONVERSIONS 

意思是：平台你自己看着来，在预算范围内尽量拿更多结果

这类策略下，运营人员可能只能改预算、定向、素材等，不能直接改一个“出价金额”



##### **一个很关键的点**

出价值的含义取决于出价策略

同样是一个数字 10，它可能是：

```
目标 CPA = 10 美元 
最高单次竞价 = 10 美元 
目标 CPI = 10 元 
目标 ROAS = 10 倍 
```

看代码或者 API 文档，千万不要只看字段叫 bid、bidAmount、bidValue，还要一起看：

```
platform 
targetLevel 
optimizationGoal 
billingEvent 
bidStrategy 
bidType 
deepBidType 
```

否则很容易误解这个数字到底是在控制什么



| 出价值类型       | 例子       | 含义                  |
| :--------------- | :--------- | :-------------------- |
| CPC bid          | $0.2       | 每次点击目标成本      |
| CPI bid          | $5.5       | 每次安装目标成本      |
| CPA / Target CPA | $10        | 每次转化目标成本      |
| Target ROAS      | 200% / 2.0 | 希望收入是消耗的 2 倍 |
| Min ROAS         | 150% / 1.5 | 最低回报要求          |
| Bid Cap          | $3         | 单次竞价出价上限      |
| Cost Cap         | $5.5       | 平均成本目标或上限    |

所以 bid=550 在我们项目里可能表示：

- 成本类：550 美分 = 5.5 美元 ROAS 类：200 = 200% = 2.0



### 出价目标

>**出价目标不是一定有一个独立选项叫“出价目标”** 
>
>它更多是一个业务理解概念，用来描述：这个出价值到底是在控制什么？

#### 基本概述

出价目标就是：我填的这个出价值，到底想控制哪个结果？

比如运营填了一个数字：2

这个数字可能代表很多东西：

- 每次点击最多 2 元 
- 每次安装目标 2 元 
- 每次购买目标 2 元 
- ROAS 目标 2 倍 

所以“出价目标”就是给这个数字贴一个业务标签



#### **三个最常见的出价目标**

##### **成本型出价目标**

这类最常见，意思是：**我希望某个行为的成本控制在多少**

常见有：

- 目标 CPC：每次点击成本
- 目标 CPI：每次安装成本
- 目标 CPA：每次转化/行动成本
- 目标 CPL：每条线索成本
- 目标 CPM：每千次展示成本

例子：

- 优化目标：INSTALL
- 出价目标：CPI
- 出价值：2 USD

大白话：*我希望每带来一个安装，成本大概控制在 2 美元*



例如：

- 优化目标：PURCHASE
- 出价目标：CPA
- 出价值：10 USD

大白话：*我希望每带来一次购买，成本大概控制在 10 美元。*



##### **回报型出价目标**

这类不是控制“花多少钱拿一次结果”，而是控制：**我花出去的钱，能不能带回来足够多的收入**

常见有：

- 目标 ROAS：广告支出回报率
- 目标 ROI：投资回报率
- 最低 ROAS：至少要达到的回报率



例子：

- 优化目标：PURCHASE
- 出价目标：ROAS
- 出价值：300%

大白话：*我希望每花 1 美元广告费，带来 3 美元收入*



##### **竞价限制型出价目标**

这类不是直接说“每个安装多少钱”，而是限制平台参与竞价时的动作

常见有：

- Bid Cap：单次竞价上限
- Cost Cap：平均成本上限/成本目标

例子：

- 出价目标：Bid Cap
- 出价值：1 USD

大白话：*每次竞价时，平台最多帮我出 1 美元*



例如：

- 出价目标：Cost Cap
- 出价值：5 USD

大白话：*平台尽量把平均结果成本控制在 5 美元附近*



不过这里要注意，Cost Cap 有时候也会和成本型目标重叠。比如：

- 优化目标 INSTALL + Cost Cap 2 USD 

业务上就会被理解成：

- 目标 CPI = 2 USD



#### 和优化目标的区别

可以这样区分：

- 优化目标：平台帮我找什么人 
- 出价目标：我想控制什么成本/回报 

比如：

- 优化目标：INSTALL 
- 出价目标：CPI 

意思是：平台帮我找更可能安装的人，同时我希望安装成本别太高



再比如：

- 优化目标：PURCHASE 
- 出价目标：ROAS 

意思是：平台帮我找更可能购买的人，同时我希望投入产出比达标



#### 和出价策略的关系

出价策略是实现方式。

- 出价目标：控制 CPA 
- 出价策略：COST_CAP 
- 出价值：10 美元 

意思是：我想控制每次转化成本，平台用成本上限/成本控制这种方式帮我做到



- 出价目标：控制 ROAS 
- 出价策略：TARGET_ROAS 
- 出价值：300% 

意思是：我想控制回报率，平台用目标 ROAS 这种方式帮我做到



所以：

- 出价目标 = 控什么 
- 出价策略 = 怎么控 
- 出价值 = 控到多少





### 业务指标

业务指标是 **投放后算出来的效果结果**，不是你在创建广告时直接“指定”的东西

比如：

- CPC = 花费 / 点击数 
- CPI = 花费 / 安装数 
- CPA = 花费 / 转化数 
- ROAS = 收入 / 花费 
- CTR = 点击数 / 展示数 
- CVR = 转化数 / 点击数 

这些是运营用来判断广告好不好



比如：

- 今天花了 100 美元，来了 20 个安装 

  CPI = 100 / 20 = 5 美元 

运营不能保证最终业务指标 CPI 一定等于 5”。

但在某些出价策略下，运营可以设置类似“目标安装成本 = 5”的出价值，平台会尽量朝这个目标优化，最终报表 CPI 可能高于、低于或接近 5。

所以：

- 业务指标 = 结果 
- 不是直接配置项
