# dev-logbook

这是我的编程学习日志本。

它不是一本教科书，也不是一个追求完整、漂亮、体系化的知识库。

更准确地说，它是我在学习编程过程中留下的一些轻量记录：  
比如一些当时没想明白的问题，一些踩过的坑，一些突然理解的瞬间，一些以后可能会忘但值得留下的东西。

## 为什么会有这个仓库

在这之前，我曾经很认真地记过很多编程笔记。

我会把一个知识点拆得很细，把概念、原理、用法、区别、示例一点点整理出来。  
看起来很系统，也很踏实。

但后来我慢慢发现，自己花了太多时间在“整理学习”上，而不是“真正学习”上。

有时候一节课没写几行代码，笔记却写了很多。  
有时候一个知识点还没真正用过，我已经开始纠结它应该放在哪个目录、怎么命名、怎么归类。  
有时候明明只是想学会一个东西，最后却变成了维护一套越来越重的笔记系统。
在我自己看来我至少浪费了70%的总学习时间。

这件事让我很是遗憾，我是一个很容易焦虑的人。

不是说那些笔记完全没用。  
它们确实记录了我当时的认真，也留下了一些思考。  
但我也不得不承认，那种方式消耗了我太多精力，甚至让我一度把“笔记写得完整”误认为是“我真的学会了”。

所以这个仓库，是一次改变。

## 这个仓库要记录什么

这里不会追求大而全。

内容可以很短，可以不完美，也可以暂时不成体系。

只要它们真实、有用、能帮到未来的我，就够了。

## 这个仓库不是什么

这个仓库不是：

- 编程教材
- 八股文大全
- 完整知识体系
- 精致排版笔记
- 为了证明“我学过”的展示品

我不想再为了写笔记而写笔记。

我希望它更像一本开发路上的随身小本子：  
遇到什么，记一点；  
想通什么，写下来；  
踩过什么坑，给未来的自己留个提醒。


**这个仓库存在的意义，不是记录一个完美的学习过程。而是记录一个真实的学习过程。**
